# tai-hub

「Sky 星を紡ぐ子どもたち」の非公式ファンツールを、1つのアプリにまとめたサイトです。

**サイト:** https://taipak5000.github.io/tai-hub/

ブラウザで開くだけで使えます。登録は不要で、スマホのホーム画面に追加するとアプリのように使えます。

## 入っているツール

| ツール | できること |
| --- | --- |
| アイテム所持管理 | ケープ・お面・髪型・衣装・楽器・家具などの所持チェック、所持率、アイテム別コスト、季節・イベントでの検索 |
| コーデ日記 | その日のコーデを写真と着ているアイテムで記録、シーズンアルバム、ランダムコーデ・マイコーデ |
| ほしいもの計画 | 欲しいアイテムに必要なキャンドル・ハートと、手に入る時期の計算 |
| エモート所持率管理 | エモートをレベルごとにチェック |
| 創作物管理ツール | シェアメモリー・シェアスペースなどの創作物の整理 |
| ノマキャン計算機 | キャンドル集めの記録と、目標に届く日の予想 |
| 星のキャンドル計算機 | 季節キャンドルの目標に届く日と、必要なペースの計算 |
| 精霊同行ツール | 精霊の連れ歩きで、目当てのアイテムまでの日数・キャンドルの計算 |
| 羽トラッカー | 光の翼をエリアごとにチェック |
| 再訪精霊データベース | 旅の精霊の来訪の記録 |
| 精霊ツリー管理 | 精霊ツリーの解放状況の記録 |
| 星紡ぎカード | 自己紹介カードの作成 |
| フレンド記念日・ふりかえり・称号一覧 | フレンドとの記念日、1年・1か月のふりかえり、各ツールの称号 |
| データ引継ぎ | ほかの端末・ブラウザへのデータの引っ越し |

ほかに、テスト中のツール（ノマキャン計算機プロ・楽譜づくり・デイリーチェックシート）があります。

## 共通の機能

- **ダッシュボード**: 今日・今週・今月の予定（季節・イベント・旅の精霊・闇の破片・大キャンドルの場所・フレンドの記念日など）。欄の並び替えと、予定をカレンダーアプリへ追加することもできます
- **お知らせ**: 旅の精霊の来訪、季節やイベントの終わり、フレンドの記念日など
- **まとめてさがす**: アイテム・楽譜・エモート・精霊・ツールを1つの欄から検索
- **着せ替え**: 画面の色・背景・質感を自由に変更（エリアをイメージした見本もあります）
- **ピン留め**: よく使うツールを4つまで、画面の上に並べられます
- **プロフィール**: 複数の保存枠を切り替えて使えます
- **更新履歴**: 関連ツールの一覧のいちばん下から見られます。新しいバージョンが出ると画面の上にお知らせが出ます

## データについて

記録したデータは、使っている端末のブラウザ（localStorage・IndexedDB）にだけ保存されます。サーバーには送りません。
別の端末で使う時は「データ引継ぎ」、または表示設定の「データのバックアップ」を使ってください。

## 開発メモ

ビルドツールを使わない、素のHTML・CSS・JavaScript（ES Modules）で作っています。
ES Modules は `file://` で直接開くと動かないため、ローカルで確かめる時は静的サーバー経由で開いてください。

```
python3 -m http.server 8000
# http://localhost:8000/ を開く
```

| 場所 | 中身 |
| --- | --- |
| `index.html` | アプリの本体（1ページ。ツールは `#/item` などの `#` 以降で切り替え） |
| `js/` | ルーター・保存・言語・ドックや設定などの共通部分 |
| `features/<ツール>/` | 各ツールの画面とデータ |
| `css/` | 共通のスタイルと各ツールのスタイル |
| `<ツール名>/index.html`・`sitemap.xml` | 検索エンジン向けの紹介ページ（`tools/build-tool-pages.py` で作成） |
